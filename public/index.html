不确定就标出来

常见问题

现在最便宜的 DeepSeek Flash 套餐是哪一个？

页面同时看两个口径：月费最低看已收录的付费订阅；单位成本最低看折算后的 ¥/1M tokens。不同平台额度和模型范围不同，建议先看口径再选套餐。

DeepSeek Flash 官方价格怎么算？

官方 API 按 token 计费，错峰和高峰价不同；本站用错峰输入和输出的 50:50 组合价作为参考，不预测实际请求比例。

WorkBuddy 的积分为什么有低置信度？

WorkBuddy 公开的是积分，不是固定 token 数。Tokenkoi 的社区实测给出约 600,000 tokens/credit 的换算，但实际会随缓存命中率和任务结构变化。

数据多久更新一次？

GitHub Actions 默认每 6 小时抓取一次；如果某次抓取失败，数据会保留并标记为 stale，下一次成功后自动恢复。

价格与条款以各平台官方页为准。本项目不构成购买建议。

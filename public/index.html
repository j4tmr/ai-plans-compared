常见问题

同样 70 元，哪家能跑的 DeepSeek Flash token 最多？

按原文的实测缓存命中率估算：OpenCode Go 约 33 亿、Command Code GOAT 约 31 亿、WorkBuddy 标准版约 24 亿，都是含缓存 token。

什么是撞墙？

OpenCode 有 5 小时和每周限额，Command Code 有 5 小时 $20、每周 $50 的额度上限。短时间猛跑时，先卡住的是这些窗口额度，而不是月额度。WorkBuddy 则是积分扣完为止。

这些 token 数是官方数字吗？

不是。官方只给美元额度或积分，token 数是按作者 2026-10-14 至 10-30 的实测用量、缓存命中率和官方单价估算出来的。

价格和限额以各平台官方页为准；token 数是实测估算，不是官方承诺。本项目不构成购买建议。
